# Concerns

## `npm run lint` reports on agent tooling, not just project source

`eslint.config.mjs` calls `globalIgnores([".next/**", "out/**", "build/**",
"next-env.d.ts"])`. That call **replaces** the ignore set `eslint-config-next`
would supply, and nothing in it covers the agent tooling directories Overdeck
drops into the workspace — `.claude/`, `.overdeck/`, `.pan/`.

Observed on 2026-08-26 at `d46242d`:

```
.claude/skills/stitch-react-components/examples/gold-standard-card.tsx
  20:10  warning  'cardData' is defined but never used  @typescript-eslint/no-unused-vars

✖ 1 problem (0 errors, 1 warning)
```

The exit code is still 0, so it does not block. It does mean a clean project
diff cannot produce a clean lint report, which makes "fix any introduced
errors" ambiguous for an agent reading the output. Tracked by AOT-1.

## No CI

`.github/` does not exist. Nothing enforces lint, tests, or the build on push
or on a pull request — the gates run only when a human or a pipeline agent runs
them. Any claim that "the branch is green" is a claim about someone's last
manual run.

## README is untouched create-next-app boilerplate

`README.md` still describes the scaffold: how to run `npm run dev`, links to
the Next.js docs, and how to deploy on Vercel. It names none of the four
routes, none of the shared components, and neither `npm run lint` nor
`npm test`. A contributor learns nothing true about this app from it. Tracked
by AOT-1.

## `AGENTS.md` is regenerated by `next dev`

The `<!-- BEGIN:nextjs-agent-rules -->` block in `AGENTS.md` is written by
`node_modules/next/dist/server/lib/generate-agent-files.js` every time
`next dev` runs. Deleting it from a diff only recreates it as an uncommitted
change. If it shows up dirty, commit it with the work rather than fighting it.

## Pricing tiers are hardcoded copy

The `tiers` array in `app/pricing/page.tsx` holds prices, feature lists, and
CTA targets as literals. There is no pricing source of truth, no currency
handling, and no localisation. That is deliberate for a demo — treat any change
to those numbers as a copy edit, not a data-model change.
